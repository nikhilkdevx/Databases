# Databases

A personal repository dedicated to learning and practicing database technologies.

## Purpose

This repository serves as my database learning journey, where I document concepts, commands, practice exercises, and projects related to both Relational and Non-Relational databases.

The goal is to build a strong foundation in database design, querying, optimization, and real-world data management.
